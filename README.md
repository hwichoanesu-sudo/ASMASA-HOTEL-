# Asmara Hotel — Independent Concept Demo

A responsive front-end concept for discussion only. It is not the official hotel website and does not make or store reservations.

## Run locally
Open `index.html` in a modern browser. Internet access is required for the linked hotel images and Google Fonts.

## Included
- Responsive layout and mobile navigation
- Room enquiry form that prepares an email draft (not a booking system)
- Map directions, telephone and email links
- Images referenced from the hotel's publicly accessible site for concept evaluation

## Before any commercial launch
- Obtain written permission to use hotel branding, photographs and copy.
- Confirm room details, facilities, rates, contact information and policies with management.
- Test all links and image loading on mobile and desktop.
- Replace the email-draft form with an approved booking/enquiry workflow if requested.
